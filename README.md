# 投資管理儀表板 PRO (Portfolio Dashboard)

專為個人與多帳號投資管理設計的全功能互動式資產配置儀表板。支援 **GitHub Pages 雲端跨裝置同步 (Firebase Auth + Firestore)**、**TradingView 即時行情與 BOATS 夜盤差額**、**FIFO 先進先出成本與拆股精算**、**主力核心 vs 衛星配置再平衡模擬**，以及 **多帳號切換與公開／不公開隱私權限管理**。

> 🛠️ **系統部署與雲端設定實作指南**：若需查看 Firebase Auth、Firestore 安全規則、`firebase-config.js` 與 Cloudflare Worker 部署教學，請參閱 👉 **[`SETUP.md` (雲端架構與設定實作指南)](./SETUP.md)**。

---

## 🌐 線上開啟網址 (遠端雲端版)

可直接透過瀏覽器（電腦、平板、手機 iOS / Android）開啟線上版：

👉 **[https://imsmallnew.github.io/portfolio-remote/](https://imsmallnew.github.io/portfolio-remote/)**

- **核心儀表板預設路由**：直接造訪網址（或帶入 `?id=main`、`?id=imsmallnew`、`?id=daniel`）即可檢視核心投資組合。
- **專屬組合網址路由**：支援透過網址參數 `?id=<組合ID>`（例如 `?id=alice`）直接進入特定使用者的專屬投資組合空間。
- **手機 App 化體驗**：iOS Safari 可點擊「分享 ➔ 加入主畫面」、Android Chrome 可點擊「加到主螢幕」，即可全螢幕如原生 App 般使用。

## 🔐 帳號切換、多租戶空間與公開／隱私設定

系統整合 **Firebase Google 身分驗證** 與 **Firestore 即時雲端資料庫**，提供靈活的多帳號體驗與嚴密的財務隱私保護：

1. **Google 帳號登入與白名單機制**：
   - 點擊右上角「**🔑 登入 / 註冊**」可使用 Google 帳號一鍵登入。
   - 尚未授權之親友可於登入畫面點擊「**📝 註冊（申請白名單）**」提交 Gmail，系統管理員可於右上角頭像選單的「**👥 授權名單管理**」中即時查看待審核申請並一鍵核准。
2. **多帳號專屬空間與自由切換 (`🗂️ 切換/查看其他組合`)**：
   - 登入後點擊右上角「**個人頭像選單**」，可隨時執行：
     - **👤 前往我的專屬維護空間**：每位獲得授權的使用者皆可建立並維護自己獨立的投資組合（擁有完整新增、編輯、刪除與匯入權限）。
     - **👑 查看 Daniel 核心投資儀表板**：一鍵返回核心主組合檢視。
     - **🗂️ 切換/查看其他組合**：輸入任意組合 ID（支援中英文、數字、底線與連字號），即可切換檢視他人已設為「公開」的投資組合。
     - **🚪 登出 / 切換 Google 帳號**：隨時切換不同 Google 身分。
3. **組合公開／不公開設定 (`🌐 隱私設定`)**：
   - 投資組合擁有者可在右上角頭像選單中一鍵切換：
     - **🌐 公開 (他人可搜尋)**：允許其他使用者透過組合 ID 切換檢視此投資組合的持股與交易表現。
     - **🔒 不公開 (僅自己可見)**：鎖定該投資組合，僅擁有者本人登入後可存取。
4. **個人總淨資產與現金儲備隱私保護**：
   - 當處於**訪客模式**或**非該組合真實擁有者本人**瀏覽時，系統會**自動隱藏敏感財務區塊**（包含頂部可收合的「💧 現金水位儲備池」、「🛡️ 儲蓄保單與本金資產」、「🏛️ 個人總淨資產 Net Worth」、生活支出與定期定額收支明細，以及分析頁籤中的三大配置總覽），僅展示證券部位數據，確保個人總資產隱私不外洩。

## 📊 六大核心功能頁籤解說

### 1. 目前持有標的 (16)
即時掌握所有有效持倉標的之最新市值與損益狀態：
- **多市場與多類別整合**：支援「全部標的」、「台股個股」、「台股 ETF」、「美股/ETF」、「基金」分類篩選與關鍵字即時搜尋。
- **FIFO 成本與即時損益精算**：自動依歷史買賣與拆股紀錄計算目前持有股數、平均成本、總投入成本 (NT$)、目前市值 (NT$)、未實現損益 (NT$)、帳面報酬率 (%) 與持倉佔比。
- **白盤即時現價 & 🌙 BOATS 夜盤現價 (差額)**：
  - 串接 TradingView 與 Cloudflare Worker 即時報價，並支援頂部「**⏱️ 定時自動更新**」（手動 / 30 秒 / 1 分鐘 / 5 分鐘 / 10 分鐘）與「**台股習慣 (紅漲綠跌) / 美股習慣 (綠漲紅跌)**」顏色切換。
  - 美股標的同步顯示 **TradingView BOATS (Blue Ocean ATS 隔夜夜盤)** 現價以及與白盤現價之即時差額。
- **TradingView 官方互動圖表彈窗**：點擊標的名稱或操作欄「📈」按鈕，立即開啟包含即時走勢看板、進階 K 線圖表與技術分析買賣信號儀表的互動視窗。
- **靈活排序與顯示控制**：
  - 支援標記「**⭐ 主力核心**」標的。
  - 支援左側 `⋮⋮` **自訂拖拉排序**，或切換依「市值高低」、「未實現損益」、「報酬率高低」排序。
  - 提供「**隱藏已出清標的 (股數 0)**」與「**顯示隱藏標的**」開關；行動裝置瀏覽時自動將「標的代號」與「名稱 / TradingView」分欄並支援水平滑動凍結檢視。

---

### 2. 買賣交易清單 (326)
完整記錄每一筆歷史與新增之交易帳本，並與持倉股數、成本及已實現損益全自動連動：
- **支援 4 種交易型態**：
  - **單筆買進**、**定期定額**、**賣出 (減持)**。
  - **股票分割 (拆股 / 反分割)**：支援設定分割比例（如 `1 拆 8 股` 或反分割小數），系統會自動將拆股基準日前所有尚未賣出的 FIFO 庫存批次按比例調整股數與每股歷史成本，總投入本金維持不變。
- **FIFO 價格與賣出結算明細**：表格完整呈現交易日期、標的代號/名稱、型態、股數、**FIFO 價格**、**賣出現價**、**成交/賣出金額**、**贖回本金 (賣出)** 與 **實際收益 (賣出)**（美股交易同步顯示 USD 原幣與折算資訊）。
- **多維度篩選與分頁**：支援依「特定標的」、「交易型態」下拉篩選與關鍵字搜尋，並提供每頁 50 筆之分頁導覽。

---

### 3. 已實現損益紀錄 (34)
彙整所有歷史已結算與賣出獲利了結／停損之獨立明細表：
- **依結算日期遞減排序**：最新結算紀錄自動排列於最上方，並支援依「特定標的」快速篩選。
- **完整結算資訊**：詳列結算日期、標的代號/名稱、賣出股數、成交賣價、買入均價/成本、計價幣別、**已實現損益 (NT$)**、**投資報酬率 (%)** 與備註說明。
- **累計損益自動對齊**：頂部與表格底部即時統計歷史已實現損益總和，並與首頁「已實現損益 (累計)」KPI 卡片同步連動。

---

### 4. 配息收入表 (14)
專為追蹤現金流與股息再投入設計的配息帳本：
- **歷次除息／發放明細**：依發放/除息日由新到舊遞減排序，支援依「特定標的」篩選與新增/編輯配息紀錄。
- **原幣與台幣自動折算**：記錄配息型態（現金股利 / 股票股利）、每股配息、參與配息股數、實領配息原幣金額（TWD / USD）及折合台幣 (NT$) 實領金額。
- **累積總報酬連動**：自動彙整歷史總配息收入，並與未實現損益、已實現損益共同計入頂部「**資產累積總報酬**」KPI 卡片。

---

### 5. 資產配置與分析圖表
結合總體資產配置、主力/衛星策略分析與互動式減持模擬器：
- **🏛️ 個人總淨資產與三大配置總覽** *(僅組合擁有者可見)*：
  - 即時聯動「**🛡️ 儲蓄保單與本金**」、「**📈 證券投資總市值 (即時)**」、「**💧 現金水位儲備池**」三大資產支柱，顯示目前佔比與規劃目標進度條。
- **⚖️ 證券持股：主力核心 vs 衛星配置損益分析**：
  - 將目前證券持倉自動拆分為左欄「**⭐ 主力核心**」與右欄「**🛰️ 衛星配置**」，即時顯示雙邊佔比 (%)、檔數、總成本與未實現損益。
  - 標題右側支援「**全部標的 / 台股 / 美股**」市場切換，以及依「**未實現損益 / 總成本**」高低排序。
- **🎛️ 主力／衛星 配置比例模擬器 & 🛰️ 衛星標的減持／出金規劃模擬器**：
  - 點擊展開模擬器滑桿（或點選 `7 : 3`、`8 : 2`、`8.5 : 1.5`、`9 : 1` 快捷比例），即時試算達成目標比例所需的「目標主力金額」、「目標衛星金額」以及**衛星需賣出回收之資金差額**。
  - 點擊「**進入規劃衛星標的**」開啟 **🛰️ 衛星標的減持／出金規劃模擬器** 彈窗：
    - 可針對各衛星標的輸入「**規劃賣出股數**」（自動檢核不可超過目前持有股數）與「**規劃賣出價格**」（預設帶入即時現價，可自由修改目標賣價），或使用「全部出清 100%」、「減持 50%」、「重置歸零」快捷鍵。
    - 支援拖曳調整標的順序、隱藏目前股數為 0 的標的、凍結左側重要欄位方便手機與桌面對照。
    - 頂部即時比對「**🎯 規劃賣出金額總和 vs 目標回收**」（顯示是否達標或尚差多少元）與「**📦 剩餘股數價值總和**」。
    - **☁️ 雲端個別儲存**：規劃內容會依登入的 Google 帳號自動同步至 Firebase Firestore，不同裝置開啟皆能接續規劃。
- **視覺化分析圖表**：
  - **資產大類配置比重**（互動甜甜圈圖）
  - **核心持股標的佔比**（互動甜甜圈圖）
  - **各持有標的未實現損益排行榜 (NTD)**（正負損益橫向長條圖）

---

### 6. 💡 投資建議 (19)
以 **先進先出法 (FIFO)** 為核心的批次停利（出金）與停損監控雷達：
- **📦 FIFO 剩餘庫存批次拆解**：
  - 自動將所有歷史買進交易扣除已賣出股數並套用拆股比例後，列出目前仍持有的每一筆獨立庫存批次。
  - 每檔標的僅於**最早一筆未出清批次**標示 `FIFO` 優先賣出標籤，方便判斷下次減持時最先沖銷的成本批次。
- **🎯 自訂出金目標 (獲利) 與 🛑 止損條件 (損失)**：
  - **出金目標 (獲利)**：可自由切換依「**獲利百分比 (%)**」（預設 `50%`）或「**獲利金額 (NT$)**」設定門檻。
  - **止損條件 (損失)**：可自由切換依「**損失百分比 (%)**」（預設 `20%`）或「**損失金額 (NT$)**」設定門檻。
- **⭐ 主力核心過濾開關**：
  - 預設**排除「主力核心」標的**，讓投資建議專注於需要波段操作或汰弱留強的「衛星配置」批次；勾選「**顯示主力核心**」即可將主力標的批次一併納入檢視，頂部四大 KPI 統計卡片亦會即時同步重算。
- **快速狀態篩選與多維排序**：
  - 點擊頂部 KPI 卡片或使用下拉選單，可快速篩選「🟢 已達到出金目標」、「🔴 已達到止損條件」、「⚪ 持有中 / 觀察中」批次，並支援依價差金額、報酬率 % 或交易日期排序。

## 📦 資料匯入與匯出備份

點擊右上角頭像選單中的「**📦 匯入 / 匯出**」，支援三種資料管理方式（限該投資組合擁有者執行）：
1. **☁️ 匯入 `data.json` (資料庫同步)**：選取本機 `data.json` 檔案，將完整交易紀錄、標的設定、已實現損益、配息與資金儲備一鍵寫入 Firebase Firestore。
2. **📤 匯出 CSV 清單**：將目前最新投資組合與交易明細匯出為標準 CSV 試算表檔案備份。
3. **📥 匯入 CSV**：從外部試算表或 SharePoint 匯出的 CSV 檔案匯入更新投資清單。
